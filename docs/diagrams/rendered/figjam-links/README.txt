Modern SIS Diagrams Bundle

This ZIP contains:
- diagrams_manifest.json: names and editable FigJam URLs for all generated diagrams
- diagrams_links.txt: quick plain-text list of diagram names and URLs

Important limitation:
The available Figma diagram generation tool in this environment exposed editable FigJam links, but did not expose direct SVG export/download endpoints. Because of that, this ZIP does not contain the actual SVG files.

To get SVGs:
1. Open each FigJam link.
2. Export the frame/diagram as SVG from Figma/FigJam.
