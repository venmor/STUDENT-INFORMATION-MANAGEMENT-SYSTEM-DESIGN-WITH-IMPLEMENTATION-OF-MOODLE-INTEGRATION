# Docs Index

This directory contains the maintained documentation for the Modern SIS project.

`main` carries the completed Phase 2 core build and the active Phase 3 Moodle integration baseline. Step 3.3 LTI delivery remains next, Step 3.4 remains the integration-verification gate after that, and the setup guide plus SRS now document a planned Phase 3.5 operational-visibility layer before the later AI-heavy phases.

## Structure

| Directory | Purpose |
|---|---|
| `project/` | Problem statement, SRS, and setup guidance |
| `architecture/` | Architecture decisions, stack rationale, and Mermaid diagrams |
| `api/` | API contract drafts and interface definitions |
| `diagrams/` | ERD, rendered diagrams, and diagram asset indexes |
| `phases/` | Phase-by-phase execution and change tracking |
| `process/` | Version control and delivery process guidance |
| `archive/` | Historical source documents retained for reference |
| `superpowers/` | Internal design/planning artifacts created during repo preparation |
